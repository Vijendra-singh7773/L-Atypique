# L’Atypique Restaurant Website

Responsive one-page restaurant and traiteur website made with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Included
- Responsive navigation and layout
- Restaurant story, menu highlights, catering, reviews and contact sections
- Click-to-call and Google Maps directions
- Local food/interior photos supplied for this website

## Menu note
Menu highlights and prices are transcribed from the supplied menu image. The menu image itself is not used as a website image. Please confirm prices and availability with the restaurant before publishing.
